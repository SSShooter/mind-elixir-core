## 大纲里 `$$` 从块变行内 —— 是我 09-13 自己加的 CSS 压平规则

用户报：`$$...$$` 在导图里是块级（正常），在大纲里变成了行内。

**根因（实测确认，非渲染器差异）**：两边用的是同一个 `renderMarkdown`，产出的 DOM 也完全一样
（`<span class="katex-display"><span class="katex">…`）；差别只有 CSS ——
`src/outliner/outliner.css:480` 的 `.outline-item-topic .katex-display { display: inline-block }`，
是我在 `d333f86`（09-13，outliner-demo 接入 markdown/KaTeX）里为了"别把行撑高"加的。

探针实测（`outliner-demo.html`，本机 23333）：

| | display | text-align | margin-top | 独占一行 |
|---|---|---|---|---|
| `#map .katex-display` | block（KaTeX 自己的） | center | 16px | ✓ |
| `#outline .katex-display`（改前） | inline-block | left | 0 | ✗ |
| `#outline .katex-display`（改后） | block | left | 0 | ✓ |

**修法**：`display: block` + `margin: 0` —— 只把 vendor 的块级角色还回去，边距仍按列表密度压掉。
改后大纲行高 41.5 → 61（公式独占一行的必然代价）。

**顺带发现：`text-align` 在 `.katex-display` 上是死声明。** 第一版修法里我写了 `text-align: left`
（想让公式随大纲行左对齐），截图一看公式其实是**居中**的 —— KaTeX 把居中声明在内层
`.katex-display>.katex{display:block;text-align:center}` 上，外层设 left 只改变
`getComputedStyle('.katex-display').textAlign` 的读取值，画面零像素差异。结论：改第三方 wrapper 的
属性前，必须先看它的内层 wrapper 有没有再声明一次。

## 用户追问"块级是不是左对齐比居中好" → 是，已改成左对齐

我第一版把 `text-align: left` 删掉了（当死声明处理），用户追问后重做测量，**证明用户的直觉对，
而且推翻了"居中 = 与导图一致"这个假设**。

实测公式**墨迹**（Range 取 `.katex-html` 的并集，不是读块盒的 left —— 块盒都是满宽，读它没意义）：

| 位置 | 公式墨迹距其容器左边 | 容器宽 |
|---|---|---|
| 导图 Fourier | **+3px**（相对它上面那行文字 = **0**） | 节点 203.5（shrink-to-fit） |
| 导图 Schrödinger | **+28.4px**（相对文字 +25.4） | 节点 170.5 |
| 大纲 居中 @1400 | **193.2 / 227.3**（两个兄弟节点各偏各的） | 行 547 |
| 大纲 居中 @900 | **68.2 / 102.3** | 行 297 |
| 大纲 居中 @620 | **0 / 32.3** | 行 160.6 |
| 大纲 左对齐（任意宽度） | **0 / 0** | — |

结论：**同一个声明在两个视图里的效果不同，因为容器的宽度语义不同。** 导图的 `.me-tpc` 是
shrink-to-fit（`width: max-content` + `:has(.katex){max-width:none}`），居中最多偏 28px、且由节点自己的
内容宽决定；大纲的 `.outline-item-topic` 是 `flex: 1`，display 盒铺满整行 → "居中"变成"在面板里居中"，
起点随面板宽度 0→193px 漂移。**所以左对齐才是与导图渲染一致的那个选择**，居中才是分歧。

最终规则（两个选择器缺一不可）：
```css
.outline-item-topic .katex-display,
.outline-item-topic .katex-display > .katex { text-align: left }
.outline-item-topic .katex-display { display: block; margin: 0 }
```
护栏测试随之扩成 4 条断言（display block ×2 + text-align left ×2）。负向对照：只保留外层
`.katex-display{text-align:left}`、删掉内层那句 → **恰好内层那条断言红、外层那条绿**，证明两句都在承重。
改回后全量 **198 passed（17.9s）**、`tsc --noEmit` 干净。
